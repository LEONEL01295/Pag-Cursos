👥 Users

GET
/api/users

Obtiene la lista de todos los usuarios

Respuesta (200)

{ "success": true, "data": [ { "id": 1, "name": "Juan Pérez", "email": "juan@example.com", "role": "student" } ] }
POST
/api/users

Crea un nuevo usuario

Body *

Campo Tipo Descripción
name string Nombre del usuario
email string Email único
password string Contraseña (mínimo 8 caracteres)

Ejemplo de Request

{ "name": "Juan Pérez", "email": "juan@example.com", "password": "SecurePass123" }
PUT
/api/users/:id

Actualiza un usuario existente

Parámetros

Parámetro Descripción
id * ID del usuario a actualizar
DELETE
/api/users/:id

Elimina un usuario

Respuesta (200)

{ "success": true, "message": "Usuario eliminado correctamente" }

📖 Courses

GET
/api/courses

Obtiene la lista de todos los cursos

Query Parameters

Parámetro Tipo Descripción
category string Filtrar por categoría
level string Filtrar por nivel (beginner, intermediate, advanced)
POST
/api/courses

Crea un nuevo curso (Solo admin)

🔐 Authentication

POST
/api/auth/login

Autentica un usuario y retorna JWT token

Body *

{ "email": "usuario@example.com", "password": "password123" }

Respuesta (200)

{ "success": true, "token": "eyJhbGciOiJIUzI1NiIs...", "user": { "id": 1, "name": "Juan Pérez", "role": "student" } }
