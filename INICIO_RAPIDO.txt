 📋 REQUISITOS (Verifica que tengas esto)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ Node.js v16+ instalado
   - Descarga aquí: https://nodejs.org
   - Verifica: abre PowerShell y escribe "node --version"

✅ npm v7+ instalado
   - Viene con Node.js
   - Verifica: escribe "npm --version"

✅ (OPCIONAL) Flutter para móvil/web
   - Descarga: https://flutter.dev/docs/get-started/install/windows
   - Necesita Git: https://git-scm.com/download/win

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ⚡ OPCIÓN 1: INSTALACIÓN AUTOMÁTICA (2 CLICKS)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  HAZ DOBLE CLIC EN:
    📄 INSTALAR.bat
    
    (Esperará a que termine, verás mensajes en verde)

2️⃣  LUEGO EJECUTA (cada uno en una terminal diferente):
    
    Terminal 1:
    📄 EJECUTAR_BACKEND.bat
    
    Terminal 2:
    📄 EJECUTAR_ADMIN.bat
    
    Terminal 3 (Opcional):
    📄 EJECUTAR_FLUTTER.bat

3️⃣  LISTO! Abre:
    🌐 http://localhost:5173
    🔧 http://localhost:3000

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 📝 OPCIÓN 2: INSTALACIÓN MANUAL (Con control total)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Paso 1: Abre PowerShell en esta carpeta
        (Shift + Click derecho → Abrir PowerShell aquí)

Paso 2: Instala Backend
        cd backend_nodejs
        npm install
        cd ..

Paso 3: Instala Admin Panel
        cd admin_panel
        npm install
        cd ..

Paso 4: (Opcional) Instala Flutter
        cd frontend_flutter
        flutter pub get
        cd ..

Paso 5: Abre 3 PowerShell diferentes en esta carpeta

        PowerShell 1:
        cd backend_nodejs
        npm run dev

        PowerShell 2:
        cd admin_panel
        npm run dev

        PowerShell 3 (Opcional):
        cd frontend_flutter
        flutter run

 🐛 PROBLEMAS COMUNES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "npm: The term 'npm' is not recognized"
   → Instala Node.js: https://nodejs.org
   → Reinicia PowerShell

❌ "Port 3000 already in use"
   → Cierra otras aplicaciones en el puerto 3000
   → O cambia el puerto en backend_nodejs/.env

❌ "Cannot find module en Backend"
   → Ejecuta: cd backend_nodejs && npm install

❌ "Flutter: Git not found"
   → Instala Git: https://git-scm.com/download/win
   → Reinicia PowerShell

❌ "Chrome not found en Flutter"
   → Usa Edge: flutter run -d edge

📖 Para más ayuda, lee: README_WINDOWS.md
